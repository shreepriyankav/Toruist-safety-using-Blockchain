┌──────────────────────────────────────────────────────────────────────────────┐
│ SYSTEM WORKFLOW                                                              │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  1. Tourist Registration                                                     │
│     → Creates Ethereum wallet                                                │
│     → Stores identity on blockchain                                          │
│     → Saves profile in MongoDB                                               │
│                                                                              │
│  2. Location Tracking                                                        │
│     → Tourist updates location                                               │
│     → System checks safe zones                                               │
│     → Calculates distance (Haversine)                                        │
│     → Updates safety status                                                  │
│                                                                              │
│  3. Geo-Fence Breach                                                         │
│     → Tourist exits safe zone                                                │
│     → Alert triggered                                                        │
│     → Incident recorded on blockchain                                        │
│     → Admin notified in real-time                                            │
│                                                                              │
│  4. AI Anomaly Detection                                                     │
│     → Monitors inactivity (30+ min)                                          │
│     → Detects unusual movement (10+ km)                                      │
│     → Generates alerts                                                       │
│     → Records on blockchain                                                  │
│                                                                              │
│  5. Incident Management                                                      │
│     → Admin views all incidents                                              │
│     → Reviews details from blockchain                                        │
│     → Resolves incidents                                                     │
│     → Updates blockchain record                                              │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
